# ✦ DreamCampus
### Student Event Discovery & Engagement Portal

A full-stack web portal built using Python-Flask and SQLite that centralises 
campus event discovery, verified student participation, and engagement tracking 
across Hyderabad colleges.

## Tech Stack
- **Backend:** Python 3.12, Flask 3.0, SQLite 3
- **Frontend:** Jinja2, HTML5 Canvas, CSS, JavaScript
- **Libraries:** Pillow, Werkzeug, Chart.js

## Features
- Phone-verified event registration
- Gamified points & leaderboard
- Dual-theme UI (Galaxy dark mode + Sunny light mode)
- Admin coordinator dashboard with analytics
- Event proposal workflow
- Image upload with Pillow processing

## How to Run
pip install flask pillow werkzeug
python app.py
Open http://127.0.0.1:5000
